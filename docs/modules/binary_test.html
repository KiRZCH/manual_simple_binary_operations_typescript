Module binary.test

Test suite for the binary sequence operations exported by binary.ts.

The suite covers the following parts of the public contract:

  • Return type: confirms that applying an operation to valid sequences returns a Binary[].
  • Input validation: verifies that an empty first sequence and an empty second sequence each cause an error with the message Arrays cannot be empty.
  • Unequal sequence lengths: checks both directions of normalization. When the source is shorter, it is left-padded with zeroes to the key length; when the key is shorter, it is left-padded to the source length. Both cases assert the resulting XOR sequence.
  • AND truth table: checks 0 AND 0, 1 AND 0, 0 AND 1, and 1 AND 1, expecting respectively 0, 0, 0, and 1.
  • OR truth table: checks 0 OR 0, 1 OR 0, 0 OR 1, and 1 OR 1, expecting respectively 0, 1, 1, and 1.
  • NAND truth table: checks 0 NAND 0, 1 NAND 0, 0 NAND 1, and 1 NAND 1, expecting respectively 1, 1, 1, and 0.
  • NOR truth table: checks 0 NOR 0, 1 NOR 0, 0 NOR 1, and 1 NOR 1, expecting respectively 1, 0, 0, and 0.
  • XOR truth table: checks 0 XOR 0, 1 XOR 0, 0 XOR 1, and 1 XOR 1, expecting respectively 0, 1, 1, and 0.
  • XNOR truth table: checks 0 XNOR 0, 1 XNOR 0, 0 XNOR 1, and 1 XNOR 1, expecting respectively 1, 0, 0, and 1.

Each truth-table case passes one-bit sequences to applySequences and compares its one-bit output with the expected Boolean result. Together, these checks exercise every possible pair of binary inputs for each supported operation.
